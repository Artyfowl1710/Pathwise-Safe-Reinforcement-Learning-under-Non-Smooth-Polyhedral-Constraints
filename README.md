# Pathwise-Safe-Reinforcement-Learning-under-Non-Smooth-Polyhedral-Constraints
Official PyTorch implementation of "Pathwise Safe Reinforcement Learning under Non-Smooth Polyhedral Constraints: A Differentiable World-Model Approach for Power Distribution Networks".




This repository provides the official implementation, differentiable simulation twin, and benchmark evaluation suite for Pathwise Safe Reinforcement Learning under Non-Smooth Polyhedral Constraints. It features physics-informed residual world modeling ($F_{\text{base}} + N_\theta$), Cimmino-averaged orthogonal projection layers, Adaptive Conformal Inference (ACI) for dynamic distribution shift, and reproducible multi-seed evaluation on the IEEE 33-bus network using real EV charging sessions from the ACN-Data corpus (Caltech & JPL).
